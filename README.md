# 🚀 Portofolio Syaiful Amin

Web portofolio modern menggunakan Next.js 15 + Tailwind CSS.

## 🔥 Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- App Router

## 📌 Fitur
- Responsive Design
- Modular Folder Structure
- Clean Architecture
- Section: Beranda, Tentang, Portofolio, Pendidikan, Pengalaman, Blog, Kontak

## 🚀 Cara Menjalankan

```bash
npm install
npm run dev
